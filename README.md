# Learning JavaScript

My journey learning JavaScript from scratch by following the **22-hour JavaScript course** by the YouTube channel **[SuperSimpleDev](https://www.youtube.com/@SuperSimpleDev)**.

This repository contains my code for **every exercise** from the course. Each exercise has its own folder, so it is easy to find, run, and review my progress.

## About This Repo

- **Goal:** Learn JavaScript step by step, from the basics to more advanced topics
- **Course:** JavaScript Full Course for Beginners (about 22 hours) by SuperSimpleDev
- **Language:** JavaScript (plus HTML and CSS where the exercises need them)
- **Author:** [tk857021-lab](https://github.com/tk857021-lab)

## How to Run

1. Clone this repository:
   ```bash
   git clone https://github.com/tk857021-lab/learning-javascript.git
   ```
2. Open the folder in a code editor such as VS Code.
3. Open the exercise folder you want.
4. Open the `.html` file in your browser (or use the Live Server extension).
